# Moon Child for GFOS

The AmiCradle Team's port of Moon Child (Reinier van Vliet's 1997 platform
game, from his 2026 SDL source release) to GFOS: AmigaOS 3.2 with
GFOpenUp, 68040/68060 + FPU, on GFOpenUp's SDL 2 and z.library.
It ships as a release archive with an Installer and as the GFOpenUp part
Parts/MoonChild.

Upstream is fetched at build time (package/moonchild.lock); this
repository holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
